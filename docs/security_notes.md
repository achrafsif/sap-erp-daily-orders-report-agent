# Security Notes

Never publish real credentials or private data in a public GitHub repository.

## Do Not Upload

- `.n8n` folder
- Gmail credentials
- Telegram token
- Telegram chat ID
- ConvertAPI token
- Groq API key
- Google Sheets private document ID
- Looker Studio private dashboard link
- ngrok token
- ngrok URLs
- Real customer or supplier data

## Important

The workflow included in this repository is sanitized. It contains placeholders only.

If a token was exposed during setup or testing, regenerate it before using the project again.
